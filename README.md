# Java DSA Journey

A structured Java learning project — 128 problems across 13 topics,
every solution tested with JUnit 5.

Built to go from Java fundamentals to being able to solve real
data-structures-and-algorithms problems independently.

---

## Structure

Each topic is a Maven module. Every problem has:
- An implementation class in `src/main/java/dsa/<topic>/`
- A JUnit 5 test class in `src/test/java/dsa/<topic>/`

```
java-dsa-journey/
├── methods/
├── arrays/
├── strings/
├── searching/
├── sorting/
├── recursion/
├── linkedlists/
├── stacks/
├── queues/
├── hashing/
├── trees/
├── heaps/
└── graphs/
```

---

## How to run all tests

```bash
mvn test
```

Run a single module:

```bash
mvn test -pl methods
```

## Rules

- Don't copy solutions.
- Attempt every problem before looking for help.
- Understand every line of code written.
- Test edge cases — not just the happy path.
- Commit each problem when tests are green.
- Record time and space complexity for DSA problems.
